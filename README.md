# For Sakshi ♡ — Test version (opens today at 9:00 PM)

A test copy of the birthday surprise website for Sakshi, locked until this evening.

## When it opens
This version stays locked until **9:00 PM IST today, 19 November 2026**.
Until then, visitors only see the lock screen with a live countdown. At 9 PM the
screen changes to show a **Click to get your surprise ♡** button — the site opens
only when she taps it. It does not open by itself.

## What's inside
- A love letter, a blow-the-candle wish with the birthday song, 23 reasons, birthday awards
- "Our moments" photo cascade and an "Our memories" 3D photo sphere with 154 photos,
  each with its own caption
- Timeline of our story, a quiz, "Open when…" letters, birthday coupons and a final gift

## How to run
Open `index.html` in a browser, or host this whole folder on any static host
(Netlify, GitHub Pages). Keep `index.html` and the `assets/` folder together.
